# Product test

DRAFT by the setup, from what John said the product is for. The strategist owns this file and keeps it current.

**The product:** A game where bees have to build a hive, make honey, and defend the hive from murder hornets.

**The test:** a person the product is for uses it for a week on their own work, on cases nobody used while building it. At the end they answer one question: would you keep using it? They also name the one thing that made them want to stop.

**Result that changes the plan:** a "no", or the same reason to stop named twice in a row. Then the strategist puts the reason to John as the week's first candidate, and no new feature starts until John has answered.

**Latest result:** none yet.
