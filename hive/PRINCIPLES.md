# Principles

DRAFT by the lead, for John to rewrite. When no rule settles a choice, these do, in this order.

1. When unsure, choose what lets the user see more and trust it; never hide.
2. If a choice costs money, cannot be undone, or changes what the product is for, it is John's; otherwise decide and write it down.
3. Nothing about one particular case goes in the code.
4. Evidence is primary sources and running the thing, never an agent's opinion, including its own.
5. Remove before adding.
6. A mistake made twice gets a mechanism.
