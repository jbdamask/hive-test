# Browser checks for spec 1

Bead hive-test-wa5 ran these checks on 2026-11-12, on main at b24298a. Every check below is a yes. The agent that ran them did not build the game.

## How the checks were run

- **Browser.** Google Chrome 157.0.8103.52 for macOS, headless, driven over the DevTools protocol by scripts in the agent's scratch folder (`~/.hive/hive-test/scratch/e-hive-test-wa5/`: `cdp.js`, `checks.js`, `play.js`, `fight.js`, `verify-record.js`). The scripts' raw output and screenshots are in the same folder.
- **Network off.** Each Chrome ran with the network emulated offline and its proxy set to a closed local port. In every run, the only requests the page made were for `file://` paths: `index.html` and the nine script files under `game/`.
- **Clicks and keys.** Every choice in a game was made with a real mouse click at the centre of the page's own button, sent as a mouse event, so the topmost element at that point received it. Space, 1 and 2 were sent as key events. The scripts read `window.beeGame` and the page's text to see what happened.
- **Fast-forwarding.** For checks 5, 6, 9 to 11 and 13, long stretches of play were stepped from the console with `beeGame.step()`, to reach a warning or the end of a season quickly. The two full games for checks 15 and 20 ran in real time from start to end, with no console stepping.

## Found along the way

The browser and run.js number days differently. The end screen counts days from 1 ("day 31 of 60" for the queen's death at tick 6001 on seed 4242), while run.js counts from 0 for the same moment ("day 30") and `--log` starts at "day 0". No check above fails because of it. It is filed as bug bead hive-test-x3n.
